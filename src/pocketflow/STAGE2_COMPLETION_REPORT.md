## 🛠️ 使用示例

### 🚀 快速啟動

```typescript
import { createPerformanceMonitoring } from "@/pocketflow/performance-monitoring";

const monitoring = createPerformanceMonitoring({
  enabled: true,
  collectInterval: 5000,
  enableRealTimeAnalysis: true,
  enableTrendAnalysis: true,
  maxMetricsInMemory: 10000,
});

await monitoring.start();
```

### 📊 性能報告

```typescript
// 獲取系統健康狀態
const health = await monitoring.manager.getSystemHealth();

// 生成性能分析報告
const report = monitoring.analyzer.generateSystemReport();

// 獲取優化建議
const optimizations = monitoring.optimizer.generateOptimizationReport();

// 預測分析
const predictions = await monitoring.predictive.generatePredictions();
```

### ⚙️ 自動優化

```typescript
// 添加自動優化規則
monitoring.optimizer.addAutoOptimizationRule({
  id: "cpu_scale",
  name: "CPU過載自動擴容",
  condition: {
    metric: "system.cpu.usage",
    operator: ">",
    value: 90,
    duration: 300000,
  },
  action: {
    type: "scale",
    parameters: { factor: 1.5 },
  },
});
```
