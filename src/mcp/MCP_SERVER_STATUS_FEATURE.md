# MCP 服務器狀態顯示功能

## 功能概述

新增了 MCP 服務器狀態顯示功能，讓用戶在聊天對話框載入時就能看到 MCP 服務器的連接狀態和可用工具，而不需要等到第一次對話後才出現。

## 功能特色

### 1. 即時狀態顯示

- 聊天對話框載入時立即顯示 MCP 服務器狀態
- 每 30 秒自動更新服務器狀態
- 顯示連接狀態、工具數量和錯誤資訊

### 2. 詳細的服務器資訊

- **服務器名稱**: 顯示每個 MCP 服務器的名稱
- **連接狀態**: 已連接/連接中/未連接/錯誤
- **工具數量**: 每個服務器提供的工具數量
- **工具列表**: 可展開查看詳細的工具列表和描述

### 3. 狀態指示器

- **綠色圖示**: 服務器已成功連接
- **藍色圖示**: 服務器連接中
- **灰色圖示**: 服務器未連接
- **紅色圖示**: 服務器連接錯誤

### 4. 聚合統計

- 已連接服務器數量
- 總可用工具數量
- 錯誤服務器數量

## 使用方式

### 查看狀態

1. 開啟聊天對話框
2. 在頂部會顯示 "MCP 服務器" 狀態面板
3. 點擊展開可查看詳細資訊

### 展開詳細資訊

- 點擊服務器條目可展開查看該服務器的所有工具
- 每個工具都會顯示名稱和描述
- 可以複製相關資訊

### 故障排除

- 如果看到錯誤狀態，點擊可查看詳細錯誤訊息
- 狀態會自動更新，或可重新載入頁面

## 技術實現

### 組件結構

```
McpServerStatus (主組件)
├── McpServerItem (單個服務器顯示)
├── 狀態載入邏輯
├── 自動更新機制
└── 錯誤處理
```

### 關鍵功能

1. **自動載入**: 組件載入時自動獲取服務器狀態
2. **定時更新**: 每 30 秒更新一次狀態
3. **錯誤處理**: 完善的錯誤顯示和恢復機制
4. **響應式設計**: 適應不同螢幕大小

### 狀態管理

- 使用 React hooks 管理本地狀態
- 與 McpToolAdapterManager 整合
- 支援設定變更檢測

## 狀態類型

### 連接狀態

- `connected`: 服務器已成功連接且工具可用
- `connecting`: 服務器正在連接中
- `disconnected`: 服務器未連接或 MCP 功能未啟用
- `error`: 服務器連接或初始化時發生錯誤

### 顯示邏輯

- 如果 MCP 整合未啟用，不顯示狀態面板
- 如果沒有任何服務器，不顯示狀態面板
- 載入中時顯示載入指示器

## 與現有功能的關係

### 與 McpToolDisplay 的區別

- **McpServerStatus**: 顯示服務器狀態和可用工具（載入時就顯示）
- **McpToolDisplay**: 顯示實際的工具調用結果（對話後顯示）

### 與設定頁面的關係

- 讀取用戶的 MCP 整合設定
- 根據設定決定是否顯示狀態
- 不提供設定修改功能（僅顯示）

## 故障排除指南

### 常見問題

1. **狀態面板不顯示**

   - 檢查 MCP 整合是否已啟用
   - 確認是否有配置的 MCP 服務器

2. **顯示 "載入中" 很久**

   - 可能是服務器連接問題
   - 檢查網路連接和服務器配置

3. **顯示錯誤狀態**
   - 點擊錯誤項目查看詳細錯誤訊息
   - 檢查服務器配置和憑證

### 調試資訊

- 在瀏覽器控制台查看詳細的載入日誌
- 錯誤會記錄在 console.error 中
