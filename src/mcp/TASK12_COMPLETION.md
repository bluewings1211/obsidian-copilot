**重點章節內容：**

#### 快速開始

```markdown
### 第一步：啟用 MCP 整合

1. 開啟 Obsidian Copilot 設定頁面
2. 切換到 **MCP 設定** 分頁
3. 開啟「**啟用 MCP 整合**」開關

### 第二步：新增您的第一個 MCP 伺服器

1. 點擊「**新增伺服器**」按鈕
2. 選擇一個 MCP 伺服器類型（建議從檔案系統伺服器開始）
3. 填寫必要的設定資訊
4. 點擊「**儲存**」
```

#### 支援的伺服器類型

- **📁 檔案系統伺服器** - 本地檔案讀寫操作
- **🗃️ 記憶庫伺服器** - 持久化對話上下文
- **🗄️ SQLite 資料庫伺服器** - 結構化資料查詢分析
- **🐙 GitHub 伺服器** - 程式碼倉庫和議題管理
- **🌤️ 天氣伺服器** - 天氣資訊查詢
